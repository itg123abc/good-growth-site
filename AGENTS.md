# Website change verification

For every website change, verify the affected page and behavior in both desktop and mobile layouts before declaring the work fully verified. Inspect image cropping, text wrapping, navigation, overflow, and any changed interactions at representative desktop and mobile viewport sizes. Keep changes scoped to the requested task.

If a browser or viewport capability is unavailable, report exactly which checks passed and which could not be performed. Source/CSS inspection alone is not a completed mobile visual check.
